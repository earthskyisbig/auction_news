# 주간 부동산 뉴스 리포트 (Jev 판독 파이프라인)

일일 브리핑(`reports/*-realestate-daily.md`)과 별개로, 주 1회 수집분을 TypeSafe Jev(System One)로
판독·선별해 작성한 주간 리포트를 아카이브한다.

## 파이프라인

```
WebFetch/WebSearch 수집 → candidates.json
  → scripts/news_jev.py           # 기사당 5문항 판독 + 코드 컷오프 → jev_news.{json,md}
  → 리포트 작성 (jev_news.md 채택 순서대로)
  → doc-eval -r news              # 리포트 자체 품질 검사, 종합 75 이상 통과
```

## 재현

```bash
# 판독 (TYPESAFE_API_KEY 필요, ~/doc-eval/.env 에서 자동 로드)
python3 scripts/news_jev.py reports/weekly/news-2026-09-23/candidates.json \
        --from 2026-09-18 --to 2026-09-27

# 임계값만 바꿔 재집계 (API 재호출 없음)
python3 scripts/news_jev.py <jev_news.json> --resummarize --min-priority 45

# 리포트 품질 검사 (scripts/rubrics/news.json 을 ~/doc-eval/rubrics/ 에 두고 실행)
cd ~/doc-eval && uv run doc-eval <리포트.md> -r news
```

## 파일

| 경로 | 내용 |
|---|---|
| `YYYY-MM-DD-weekly-news.md` | 주간 리포트 본문 |
| `YYYY-MM-DD-weekly-news.html` | 같은 내용의 웹 브리핑 (algo-design 토큰: 크림 배경 + 오렌지/블루 액센트). 카테고리 칩 필터·우선순위 막대·두 기관 통계 비교 포함 |
| `news-YYYY-MM-DD/candidates.json` | 수집 원본(판독 입력) |
| `news-YYYY-MM-DD/jev_news.md` | 판독 결과 — 채택·제외 사유·영향도·방향 |
| `news-YYYY-MM-DD/jev_news.json` | 판독 원자료(확률 분포·토큰 사용량 포함) |

## 의존하는 저장소

이 저장소는 산출물과 자동화 래퍼만 갖는다. 실행 로직은 다른 두 저장소에 있다.

| 필요한 것 | 저장소 | 로컬 위치 |
|---|---|---|
| `budongsan-news` 스킬 (Step 1~7), `news_jev.py` | `earthskyisbig/claude-skills-private` | `~/claude-skills/` → `~/.claude/skills/` 심링크 |
| `doc-eval` CLI, `news` 루브릭 | `earthskyisbig/doc-eval` | `~/doc-eval/` |
| `TYPESAFE_API_KEY` | (저장소 없음) | `~/doc-eval/.env` |

사본을 이 저장소에 복사해 두던 방식(`scripts/news_jev.py`, `scripts/rubrics/news.json`)은
원본과 갈라지므로 2026-09-26에 제거했다. 새 맥에서는 저장소 3개를 클론하고
`~/claude-skills/README.md`의 심링크 스니펫을 돌린 뒤 비밀값을 채우면 된다.

## 판독 결과 읽는 법

- **우선순위(0~100)** = 영향도 정규화 + 출처 티어 보정(T1 +5 / T3 −10) − 전망성 10 − 수치 미명시 5
- **영향도 x.x/4** — 4에 가까울수록 시장 규칙 자체가 바뀌는 사안(기준금리·대출 총량·공급대책)
- Jev는 본문에 적힌 것만 판단한다. **선별 근거이지 사실 검증이 아니다** — 채택 기사 수치는 원문 확인이 필요하다.
- 영향도는 전국 파급을 보므로 국지 뉴스가 컷오프 아래로 떨어진다. 리더가 복원할 경우 리포트 본문에 그 사실을 명시한다.

## 자동 실행

`scripts/run-weekly.sh`가 crontab에서 **매일 07:00** 호출되고, 실행 여부는 스크립트가 정한다:

| 조건 | 동작 |
|---|---|
| 이번 주(ISO 월~일) 스탬프 있음 | 종료 — 이미 돌았다 |
| 금요일 이전 | 종료 — 아직 이르다 |
| 금·토·일 + 스탬프 없음 | 실행 — 금요일에 맥이 꺼져 있었으면 토·일에 보정된다 |

금요일을 기준으로 삼은 이유는 한국부동산원 주간동향이 목요일에 나오기 때문이다.
판독 기간은 직전 목요일부터 실행일까지로 잡는다.

- 스탬프: `_workspace/weekly/.done-YYYY-Www` (gitignore). 산출물이 실제로 생겼을 때만 기록하므로,
  실패한 주는 다음 날 다시 시도된다.
- 락: `_workspace/weekly/.lock` — 06:30 일일 브리핑과 겹칠 때 중복 실행을 막는다(3시간 지나면 회수).
- 로그: `logs/weekly_YYYYMMDD.log`
- 푸시 인증: **deploy key**. cron은 GUI 키체인에 접근할 수 없어 https + osxkeychain 조합이 실패한다
  (2026-09-25 실제로 커밋만 쌓이고 푸시가 조용히 멈췄다). 원격은 `git@github-auction-news:...` 별칭을 쓰고,
  키는 `~/.ssh/auction_news_deploy` — **이 저장소에만** 통하므로 유출돼도 다른 저장소·계정은 안전하다.
  ssh 별칭 정의는 `~/.ssh/config`. 되돌리려면
  `git remote set-url origin https://github.com/earthskyisbig/auction_news.git`.
- 푸시가 실패하면 텔레그램으로 알린다(`notify_push_failure`). 로그에만 남기면 아무도 모른다.
- 실행 내용은 전역 스킬 `~/.claude/skills/budongsan-news/`의 Step 1~7이다. 스킬이 없으면 이 자동화도 돌지 않는다.

수동으로 한 회차 돌리려면 스탬프를 지우고 스크립트를 부르거나, 대화에서 `/budongsan-news`를 쓴다.

```bash
rm -f _workspace/weekly/.done-$(date +%G-W%V) && ./scripts/run-weekly.sh
```

### 2026-09-25 회차 메모

판독 기간이 **9/24(목)~9/25(금) 2일**이고 그중 9/25가 추석 당일이었다. 후보 16건 중 9건이 기간 외로
탈락했고, 채택 6건 중 3건이 같은 한국부동산원 발표(9월 3주)를 다룬 기사였다. **금리·거시경제·지역별
소식·경매 세 섹션이 기간 내 자료 0건**이어서 리더가 기간 직전 3건(한은 금융안정 9/22, 서울 경매
낙찰가율 9/18, 경기 10월 분양 9/23)을 복원하고 본문·HTML에 모두 복원 표시를 달았다.

교훈: **연휴가 낀 주는 2일 창으로 잡으면 섹션이 구조적으로 빈다.** `run-weekly.sh`가 직전 목요일부터
잡는 기본 규칙은 평상시에는 맞지만, 공휴일이 끼면 `--from`을 한 주 앞으로 늘리는 편이 낫다.
한국부동산원·한국은행 보도자료 게시판은 이번에도 SPA라 WebFetch에 실패해 언론 인용본을 썼다.

### 2026-10-02 회차 메모

판독 기간은 **10/1(목)~10/2(금)** 2일 창이었고, 그중 **10/2자 신규 기사는 끝까지 0건**이라 사실상 1일분이다.
후보 14건 중 Jev 채택 9건, 제외 5건(기간 외 4·우선순위 미달 1)인데 **리더가 제외 5건을 전부 복원**했다.
복원이 많은 것은 판단이 후해진 게 아니라 금리·경매·임대차·입법 네 축이 기간 내 0건이었기 때문이다.
**제외 0건은 선별이 잘됐다는 뜻이 아니라 후보 자체가 적었다는 뜻**이므로, 이 비율을 성과로 읽지 말 것.

또 직전 회차(9/25) 이후 **9/26~9/30 구간은 어느 주간 리포트에도 담기지 않았다**(지정 기간을 따랐다).
필요한 2건(전세 갱신계약 9/30, 분양 물량 집계)만 복원으로 끌어왔다. 창을 좁게 잡으면 구멍이 남는다.

#### 적발: 2018년 경매 통계가 일일 브리핑에 2026년 수치로 들어가 있었다

일일 브리핑 10/1·10/2자의 '2026년 9월 월간 경매 지표'
— **전국 진행 8,341건 / 낙찰 3,018건(역대 최저) / 업무상업시설 낙찰가율 61.2%** —
는 원문 fetch 결과 **디지털타임스·이데일리 2018-10-15 기사**의 수치였다. 주간 리포트에서 제외하고 정정 표를 실었다.

- 발견 경로: `WebSearch "9월 지지옥션 월간 역대 최저 낙찰건수 2026"` → 같은 수치가 2017·2018년 기사로 노출 → 일일 브리핑이 인용한 URL 2건을 직접 `WebFetch`해 발행일 확인.
- 원인: 검색 엔진이 **연도 없는 "9월 경매" 질의에 과거 기사를 섞어** 올린다. 일일 수집가는 같은 질의에서 2017년 "낙찰률 37.8%"는 걸러냈으나 3,018건은 통과시켰다.
- 규칙: **경매·청약 통계는 URL이나 본문에 연도가 박혀 있는지 확인한 뒤 인용한다.** 기사 ID만 보고 최신으로 가정하지 말 것(`dt.co.kr/article/11195750`은 2018년 ID였다).
- 같은 회차에서 "10월 1주차(10/4~10/7) 서울 낙찰가율 87.8%·응찰 1.9명"(기준일이 미래), "검암역 푸르지오 18.96:1"(실제 2026-09-02 기사)도 같은 패턴으로 배제했다.

#### fetch 결과

- **한국은행 기준금리 페이지는 이번 회차에 fetch 성공**(3.00%, 1차 출처 확인). 단 자동 파싱이 변동 방향을 '인하'로 잘못 읽어, **금리 수준 추이(2.50→2.75→3.00)로 인상임을 확정**했다. 표의 화살표를 그대로 믿지 말 것.
- 국토교통부 보도자료 게시판(`m_71/lst.jsp`)은 **리다이렉트 10회 초과로 실패**. 정책 2건은 언론 인용본으로 작성했다.

### 2026-10-09 회차 메모

판독 기간은 **10/8(목)~10/9(금)** 2일 창이고 **둘째 날이 한글날**이었다. 정책브리핑·국토부 목록 확인 결과
**10/9자 신규 발표는 0건**이라 기간 내 자료는 사실상 10/8 하루분이다. 후보 21건 중 Jev 채택 8건, 제외 13건
(기간 외 10·우선순위 미달 3)이고 리더가 **11건을 복원**했다.

**9/25 → 10/2 → 10/9, 같은 구조적 결손이 세 회차 연속이다.** 2일 창 + 공휴일 조합이면 경매·금리·청약·입법이
구조적으로 빈다. 이번에는 **경매 섹션이 채택 0건**, 금리·청약이 각 1건이었다. `--from`을 한 주 앞으로
늘리는 것은 더 이상 권고가 아니라 **연휴 주의 기본값으로 삼아야 한다.**

#### 채택 8건 중 6건이 같은 발표의 파생 기사

그 하루(10/8)가 **한국부동산원 주간동향(10.05 기준) 발표일**이었다. 10/2 회차에서 "발표 대기"로 비워 둔
지표가 이 창에서 확정됐다는 점은 좋지만, 결과적으로 채택 8건 중 6건(서울 87주·전세 역전·강남3구·생존 매수·
경기·지방)이 **동일 발표의 파생**이다. 중복 판정(제목 자카드 0.4 + 공유 숫자 2개)으로는 안 잡힌다 —
서로 다른 구·지표를 다루므로 기사로는 별개다. **"채택 N건"을 커버리지로 읽으면 안 된다는 사례.**

#### 복원률 58%(11/19)를 성과로 읽지 말 것

10/2 회차 교훈의 재확인이다. 복원이 많은 것은 판독이 후한 게 아니라 후보 모수가 작기 때문이다. 다만 이번에는
복원 사유가 한 가지 더 있었다 — **우선순위 72(후보 21건 중 2위)인 불법하도급 집중단속이 날짜 하나로 탈락**했다.
단속 개시일이 10/12로 다음 주여서 실행 가치가 가장 큰 항목인데 컷오프 전에 기간 필터에서 떨어진다.
**`--from` 범위와 '실행 시점이 미래인 항목'은 별개 축**이라는 걸 보여준다.

복원하지 않은 2건은 국토위 국감 산하기관 감사(우선순위 18, 복원한 10/7 국감 답변과 중복)와
오세훈 시장 SNS 분석(우선순위 7, 정치 논평·시장 수치 없음)이다.

#### 직전 회차 교훈 2건을 적용했고, 둘 다 작동했다

- **금리 페이지 화살표**(10/2 교훈): fetch 프롬프트에서 **"화살표나 방향 해석을 하지 말고 날짜와 금리 수치만
  그대로"**로 요청해 수준 추이(2.50→2.75→3.00)로 방향을 재구성했다. 오독 없었다.
- **연도 트랩**(10/2 교훈): 경매 검색에서 "낙찰가율 97.3% 4년 만 최고", "102.9% 3년 6개월 만 최고" 등
  과거 연도 기사가 상위에 혼입됐다. 채택 수치(전국 85.9%·서울 94.7%)는 2026-10-07자 복수 매체 원문에서
  "2026년 9월" 명시를 확인한 것만 사용했다. 시장·청약 검색에서도 2024·2025년 부동산원 주간동향 기사가
  섞여 올라와 전량 배제했다.

#### fetch 결과 — 부동산원 게시판은 목록만 열린다

- ✅ **한국부동산원 보도자료 게시판**: 글번호·제목·등록일 목록 확인 성공(1946 「주간아파트가격동향(20261005기준)」,
  2026-10-08 등록). 단 **상세 본문 URL(`selectNttInfo.do?nttSn=1946`)은 "시스템안내" 페이지만 반환**해
  개별 수치는 세계일보·아시아경제 원문 fetch로 교차 확인했다. **목록 fetch로 "발표됐다"는 사실만 1차 확인하고
